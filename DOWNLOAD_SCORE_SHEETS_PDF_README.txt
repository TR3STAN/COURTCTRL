COURTCTRL - Downloadable Score Sheets

The Printable Score Sheets page now has a Download PDF button.
Click it to open the browser's built-in print/export dialog. Select "Save as PDF" as the destination and click Save. This works offline and keeps the existing Legal portrait layout with six score sheets per page.

The PDF filename is based on the tournament name and selected game date.
The printable Game / Order number remains unique for each sheet.

Install:
1. Back up the current project folder and database.
2. Extract this ZIP.
3. Copy the included pickleball_tournament folder into C:\xampp\htdocs\ and replace the existing files.
4. Refresh the local COURTCTRL site.
5. Open Live Feed > Generate score sheets > Download PDF.
6. In Chrome's print dialog, set Destination to Save as PDF, then Save.
