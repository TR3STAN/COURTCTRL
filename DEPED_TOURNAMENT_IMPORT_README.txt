Import steps
------------
1. Back up/export the current MySQL database in phpMyAdmin.
2. Extract this ZIP into C:\xampp\htdocs\, replacing project files when prompted.
3. Start Apache and MySQL in XAMPP.
4. Visit:
   http://localhost/pickleball_tournament/import_deped_tournament.php
5. Check the confirmation box and click Import DEPED Tournament once.
6. After success, open the Tournament Workspace link shown on the page.
7. Delete import_deped_tournament.php and deped_tournament_entries.json after a successful import.

Important behavior
------------------
- Import creates real database records; it is not a preview.
- A duplicate tournament name is detected and the import is stopped.
- The provided bracket assignments are preserved exactly as Bracket A, B, etc.
- Every team in a group is paired against every other team in that same group,
  creating Round Robin fixtures.
- Elimination matches are not generated by this import. Use Scoring & Standings
  after all group matches are completed to generate elimination rounds.
- Match schedules are not generated. Use Schedule & Courts to assign dates/times/courts.
- Player gender is filled as Male/Female for clearly labelled Men's/Women's
  categories. For mixed/coed/40 UP, gender is left blank because the provided
  list does not identify each partner's gender.
- The 40 UP category is named exactly "40 UP".
- The import script uses 4 courts as a starting value; change this if needed.

Validation
----------
The import script passed PHP syntax validation. The import itself must be run
against the user's XAMPP database. Do not run it twice.
