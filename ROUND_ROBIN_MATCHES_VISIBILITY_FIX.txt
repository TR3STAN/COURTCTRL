COURTCTRL - Round Robin Matches Visibility and Court Grouping Fix

Root cause:
- The scoring page only set $activeStage during POST requests. On a normal GET page load, the Round Robin stage pane did not receive its "active" class, so the match area stayed hidden even though the tab counter showed 50 matches.

Fixes:
- Initialize the active stage to Round Robin on normal page loads (GET).
- Preserve the selected stage on POST and allow active_stage=elim in the URL.
- Retrieve match_schedules.court_id as assigned_court_id to avoid ambiguous duplicate court_id keys from SELECT m.*.
- Group all Round Robin matches under their existing court assignment and retain a fallback group only if a match truly has no court.
- Category and bracket labels remain visible; court reassignment remains optional and collapsed.

Install:
1. Back up the current project folder and database.
2. Extract this ZIP.
3. Copy the included pickleball_tournament folder into C:\xampp\htdocs\ and replace existing files.
4. Refresh Scoring & Standings. Open the Round Robin tab if needed.

Validation:
- PHP syntax check passed for scoring.php.
- Browser/database runtime testing was not performed in this environment.
